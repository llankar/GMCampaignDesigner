# Contribuer

1. Ouvrir une proposition ciblée et relier la décision d’architecture concernée.
2. Créer une branche courte, ajouter le code et les tests dans des fichiers séparés.
3. Configurer et compiler avec les presets documentés dans le [guide CMake](docs/development/cmake-guidelines.md).
4. Exécuter les contrôles de la [stratégie de test](docs/development/testing-strategy.md), puis mesurer en Release tout chemin critique.
5. Soumettre une revue décrivant comportement, risques, migration de données et résultats de test.

Les commits ne contiennent ni campagne réelle, ni secret, ni chemin local. Les contributions acceptent la licence du projet et documentent toute nouvelle dépendance dans [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
