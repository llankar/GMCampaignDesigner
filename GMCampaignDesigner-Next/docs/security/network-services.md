# Services réseau

Tout serveur local écoute sur loopback par défaut, utilise port configurable non privilégié, authentification de session et limites de requête. L’exposition LAN est une action explicite, visible et révocable; les vues joueur ne reçoivent que les données publiées. TLS est requis hors machine.
