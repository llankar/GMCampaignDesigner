# Format de campagne

Une campagne associe une base SQLite versionnée à des médias adressés par identifiants stables. L’export est une archive manifestée : version, empreintes, tailles et chemins relatifs normalisés. Les lecteurs valident avant extraction et ignorent sans perte les extensions déclarées.
