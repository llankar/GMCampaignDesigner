# Organisation des médias

Les médias sont stockés sous une racine de campagne avec noms internes dérivés d’identifiants, jamais de noms utilisateur non filtrés. Métadonnées, original et variantes sont séparés; empreinte, type détecté et taille sont vérifiés. Les miniatures sont reconstructibles et chargées asynchronement.
