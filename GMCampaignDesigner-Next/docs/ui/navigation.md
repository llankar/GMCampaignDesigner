# Navigation

Les destinations possèdent identifiant stable, titre et commande. L’historique avant/arrière conserve contexte sans garder de lourdes vues vivantes. Raccourcis, focus initial et retour au déclencheur sont déterministes; les routes refusent les entités supprimées.
