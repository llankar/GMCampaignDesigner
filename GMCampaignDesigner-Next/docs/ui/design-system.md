# Design system

Les tokens nommés définissent couleurs, typographie, espacements, rayons et mouvements; les composants consomment les tokens plutôt que des valeurs dispersées. États focus, survol, pressé, désactivé, chargement et erreur sont visibles et compatibles contraste.
