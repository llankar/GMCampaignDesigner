# Versionnement

Les versions publiques suivent MAJEUR.MINEUR.CORRECTIF : rupture de format/API, fonctionnalité compatible, puis correction. Les versions de schéma évoluent séparément et leur compatibilité est documentée. Les préversions portent un suffixe et ne sont jamais présentées comme stables.
