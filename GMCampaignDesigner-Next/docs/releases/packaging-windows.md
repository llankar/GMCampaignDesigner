# Packaging Windows

Le paquet Release est construit dans un environnement propre, inclut uniquement DLL Qt et runtimes requis, licences/notices, puis est signé. Un test sur machine vierge couvre installation, lancement, mise à niveau, associations et désinstallation sans supprimer les campagnes utilisateur.
