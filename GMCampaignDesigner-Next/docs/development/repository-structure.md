# Structure du dépôt

`src` suit les couches de l’architecture; `tests` reflète les modules; `benchmarks` contient scénarios et générateurs; `docs` porte les décisions; `packaging` reste spécifique aux plateformes. Chaque cible possède son sous-répertoire et un CMakeLists focalisé.
