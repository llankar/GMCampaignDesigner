# Compatibilité historique

Un inspecteur en lecture seule détecte les versions historiques et traduit vers un modèle intermédiaire documenté. Les ambiguïtés deviennent avertissements ou rejets explicites; aucune supposition silencieuse ne fabrique de données. La compatibilité est une matrice versionnée et couverte par fixtures anonymisées.
