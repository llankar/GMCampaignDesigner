# GMCampaignDesigner Next

GMCampaignDesigner Next est la réécriture C++23/Qt 6 du concepteur de campagnes. Le projet privilégie une architecture testable, une interface réactive et une migration sûre depuis l’application historique.

## Point de départ

- Consulter l’[index documentaire](docs/README.md).
- Installer l’environnement décrit dans le [guide de démarrage](docs/development/getting-started.md).
- Lire les [règles de contribution](CONTRIBUTING.md) et les [contraintes d’architecture](docs/architecture/overview.md).
- Signaler une vulnérabilité selon la [politique de sécurité](SECURITY.md).

Le dépôt contient à ce stade le socle de gouvernance, la documentation d’architecture et une configuration CMake minimale validable sans dépendance Qt installée.
